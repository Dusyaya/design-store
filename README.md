# Портфолио ATROKHINA

Статическое портфолио на HTML, CSS и JavaScript. Эта версия подготовлена к публикации из репозитория `Dusyaya/design_store_2`.

Для локального просмотра из корня проекта выполните `python -m http.server 8000` и откройте `http://localhost:8000/`.

[Предпусковой чек-лист и результаты проверки](LAUNCH-CHECKLIST.md)

## Где редактировать тексты

- **content.js** — все тексты главной страницы, контакты, подписи и навыки.
- **projects.js** — карточки и подробные описания всех проектов. Каждый проект оформлен отдельным объектом с отступами.
- **styles.css** и **light.css** — базовые стили кейсов, светлая тема и адаптивная сетка.
- **book-reader.js** — перелистывание книги и зина.
- **home.js** — логика главной страницы, фильтры.
- **project-page.js** — единый шаблон для всех страниц проектов.
- **shared.js** — общие функции, ссылки и загрузка изображений.

**Не нужно редактировать HTML для изменения текстов.**

## Отдельные страницы

Каждый проект доступен по адресу `projects/ID/`. Например:

- `projects/laser/`
- `projects/gold/`
- `projects/babushka/`

У каждой страницы свой файл `index.html`, но оформление и тексты подключаются из общих файлов. Это исключает дублирование кода.

## Замена изображений через GitHub

- Портрет: `assets/IMG_4855-clean.jpg`. Для узких экранов используется кадрированный вариант `assets/portrait-clean-mobile.jpg`.
- Обложки находятся в `assets/project-covers/`. Каталог использует `cover-XX.webp`, шапка кейса использует `cover-XX-hero.webp`, увеличение открывает `cover-XX.png`.
- Логотип Blender: `assets/blender_logo.png`.
- Фото проекта: `assets/projects/ID/1.webp`, `2.webp`, `3.webp`.

Изображения загружаются из текущего репозитория по относительным путям. При замене портрета обновите обе версии JPG. Для JPG и PNG внутри `assets/projects/` добавляйте облегчённую копию с расширением `.webp` после исходного имени, например `slide-01.jpg.webp`. Сайт использует эту копию в кейсе, а при увеличении загружает полноразмерный файл. Для печатных изображений в CMYK подготовьте полноразмерную версию в sRGB и соответствующую миниатюру.

## Как добавить новый проект

1. Добавьте объект в массив `PORTFOLIO_PROJECTS` в `projects.js`.
2. Создайте `projects/НОВЫЙ_ID/index.html` по образцу существующей страницы, заменив `data-project` / идентификатор в строке `document.body.dataset.project`.
3. Добавьте фотографии в `assets/projects/НОВЫЙ_ID/`.

## Развёртывание

GitHub → Settings → Pages → Deploy from a branch → main → / (root).
