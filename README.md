# ATROKHINA — Design Store

Портфолио Дарьи Атрохиной: статический сайт HTML/CSS/JS.

## Публикация GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.

## Изображения
В страницах проектов оставлены плейсхолдеры. Загружайте оригиналы в assets/projects/<id>/1.webp, 2.webp, 3.webp и заменяйте соответствующие блоки в script.js на img.

## Исследования
Разделы исследования содержат концептуальные ориентиры и гипотезы, не вымышленные результаты тестов.
