# Портфолио ATROKHINA

Статический сайт на HTML, CSS и JavaScript. Публикация через GitHub Pages.

## Где редактировать тексты

- **content.js** — все тексты главной страницы, контакты, подписи и навыки.
- **projects.js** — карточки и подробные описания всех проектов. Каждый проект оформлен отдельным объектом с отступами.
- **styles.css** — общий дизайн, цвета и адаптивность.
- **home.js** — логика главной страницы, фильтры.
- **project-page.js** — единый шаблон для всех страниц проектов.
- **shared.js** — общие функции, ссылки и загрузка изображений.

**Не нужно редактировать HTML для изменения текстов.**

## Отдельные страницы

Каждый проект доступен по адресу `projects/ID/`. Например:

- `projects/laser/`
- `projects/gold/`
- `projects/babushka/`

У каждой страницы свой файл `index.html`, но оформление и тексты подключаются из общих файлов. Это исключает дублирование кода.

## Замена изображений через GitHub

- Фото на главной: `assets/profile.webp`.
- Логотип Blender: `assets/blender_logo.png`.
- Фото проекта: `assets/projects/ID/1.webp`, `2.webp`, `3.webp`.

Заменяйте файл с тем же именем через GitHub. Сайт проверяет актуальную версию файла и обновляет адрес изображения. Для новых изображений кейса создайте соответствующую папку в `assets/projects/` (GitHub создаёт папку при добавлении файла по пути).

## Как добавить новый проект

1. Добавьте объект в массив `PORTFOLIO_PROJECTS` в `projects.js`.
2. Создайте `projects/НОВЫЙ_ID/index.html` по образцу существующей страницы, заменив `data-project` / идентификатор в строке `document.body.dataset.project`.
3. Добавьте фотографии в `assets/projects/НОВЫЙ_ID/`.

## Развёртывание

GitHub → Settings → Pages → Deploy from a branch → main → / (root).
